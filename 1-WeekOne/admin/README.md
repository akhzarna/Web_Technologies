# Admin (a future lecture)

There is no admin UI or admin API yet. For this lecture, edit
`server/data/books.json` to add or change demo books, then refresh the page.
The server reads this file on each API request; no restart is needed.

In a later lecture, this folder can hold an admin page for creating, editing,
and deleting books with POST, PUT, and DELETE requests. Authentication and
input validation should be introduced with those features.
